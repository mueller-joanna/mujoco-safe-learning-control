## Venv
It is recommended to use python in project-specific virtual environment. The most basic tool is [Python3-venv](https://docs.python.org/3/library/venv.html).

## Poetry
Dependency management with [poetry](https://python-poetry.org/docs/#installation) (Install with Pipx).
Activation of env
```
source ~/.local/pipx/venvs/poetry/bin/activate
```
- Create `poetry.lock` to save specific versions of dependencies
